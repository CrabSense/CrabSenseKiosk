# P2.1 — Water bench UART integration (supervised)
Separate from signed HTTP Edge V2/RAS, no changes to existing telemetry or SQL schema. Firmware main dce1464, Modbus V4 internal to controllers, Kiosk UART 115200 8N1. Configure two distinct USB-UART COM ports and exact lowercase 12-hex hardware IDs from local INVENTORY; identity is configured physical-port binding, not cryptographic authentication or BE registration. Verify adapters, DTR/RTS reset behavior and stable power; no other program may own ports. Default WaterBench:Enabled=false and EnableSupervisedControl=false. No automatic reconnect/replay after uncertain disconnect. Inspect hardware and restart Kiosk service only after recovery. Use dummy loads before any real operation.

Set WaterBench__Enabled=true, MasterPort, SlavePort, MasterHardwareId, SlaveHardwareId in local configuration. Set WaterBench__LocalOperatorKey via protected environment/secret, at least 32 chars; never commit it. EnableSupervisedControl only for supervised commissioning. Endpoints only direct loopback with X-Water-Bench-Key, no browser Origin; do not expose through proxy or tunnel. Existing application authorization is not used as proof of hardware operator identity. GET /api/water-bench/status reports manifests, latest firmware batch/clean status, raw telemetry tokens and receipt times, NH3 sample evidence, verified capture IDs and recovery required. POST /api/water-bench/command accepts requestId UUID, action, id (1 NO2, 2 NO3, 3 NH3), mask (bits 1,2,4), captureId, values. Actions: assayProfile (existing firmware measured profiles), cleanProfile (6 measured values after vial ID), manual (mask), scheduled (mask 7), route, confirm, optical, image (correct analyte and verified stored capture), batchReset, cleanStart, cleanRoute, cleanVerify, cleanReset, batchStatus, cleanStatus, stop. No raw serial/pulse/ARM. Explicit local operator action only. HTTP 202 means written to UART, NOT firmware acceptance or physical action complete. Inspect status and firmware responses; do not automatically resend. STOP best effort only, not hardware e-stop. Manual mixing/powder/route/optical confirmations required as before.

Master BATCH START/SESSION/IMAGE events correlated with slave CAM BEGIN/DATA/END. Enforce configured board IDs, 55 KiB JPEG cap, exact offsets, CRC32, JPEG envelope, full decode and declared dimensions. Image evidence bound to active batch/analyte/session/capture on same connection; never automatically confirm chemical result. CRC does not prove sample identity/exposure quality. Single-assay images outside batch not associated. NH3 SAMPLE uptime and Kiosk receipt UTC retained; no assertion of synchronized sampling or actual exposure UTC. Raw sensor tokens include invalid values, not invented readings; no TDS-to-salinity conversion.

Evidence spool directory must be local protected storage (not public wwwroot), backup and monitor capacity, default 256 MiB/20000 files. Each event or frame is immutable file with pending upload status and random local media ID; no deletion/automatic upload. Command audit create-once before serial write. Incomplete temporary/orphan files may exist after disk/power loss; inspect on recovery. Full spool or malformed wire data latches recovery required and prevents further normal commands. No automatic hardware STOP on Kiosk failure; firmware watchdog and physical operator protections remain essential. SkiaSharp 3.119.4 (MIT) replaces ImageSharp; Linux NoDependencies native assets and transitive Win32 assets support .NET 8. JPEG acceptance requires a successful full pixel decode, not just an image header or partial bitmap. Preserve third-party notices and monitor dependency updates. CI tests the decoder on Linux and Windows. P2.1.1 adds a durable daily schedule with automatic due slots and explicit operator approval; see water-bench-schedule.md. Remaining: acknowledgements correlated with command IDs, BE registration/upload/acknowledgment and retry protocol, persistent UTC alignment, physical test. No real device test or autonomous chemistry.
